## 🚀 How to Use Your Website

### **Local Testing**

1. **Open index.html**
   - Simply double-click `index.html`
   - OR right-click → "Open with" → Choose your browser

2. **Navigate the site**
   - Homepage shows shop info and tagline
   - Click "श्रेणी पहा" (Browse Categories)
   - Select any category (Vegetables, Crops, Flowers, Fruits)
   - View all items in that category with images

3. **Test language switching**
   - Click the language button in top-right corner
   - Toggle between Marathi ↔ English

### **Deploy to GitHub Pages**

```bash
# Navigate to project folder
cd "d:\Projects\Agree Portfolio\agro-website"

# Add and commit changes
git add .
git commit -m "Website fully restored with all 56 images"

# Push to GitHub
git push origin main
```

Then enable GitHub Pages in repository settings:
- Settings → Pages
- Source: `main` branch → `/ (root)` folder
- Save

Your site will be live at: `https://[username].github.io/[repository-name]`
